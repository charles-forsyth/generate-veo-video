Generate-Veo-Video: Professional Text-to-Video, Animation, and Interpolation CLI

A professional CLI tool for generating and extending videos using Google's Veo 3.1 models (standard, fast, lite) via the Gemini Developer API or Vertex AI.

uv tool install --python 3.12 git+https://github.com/charles-forsyth/generate-veo-video.git
View Repository Explore Terminal Output

Key Capabilities

Designed and tuned for modern terminal workflows and automated pipelines.

✨

Veo 3.1 Text-to-Video

Generate 720p video clips with synchronized audio from rich natural language descriptions.

✨

Image Animation & Morphing

Animate static images or interpolate smoothly between first and last frames.

✨

Style & Reference Guidance

Guide character consistency and visual aesthetics using up to 3 reference images.

✨

Veo Video Extension

Extend previously generated clips for seamless multi-scene continuous playback.

Usage Examples

Quick command recipes for terminal operations.

Text-to-Video

Generate 8-second cinematic video with audio:

generate-veo "A cinematic drone shot of a futuristic city at night, neon lights, rain." --duration 8

Image Animation

Animate a static photograph:

generate-veo "Make the waves move and the clouds drift." --image ./ocean.png

First-to-Last Frame Morph

Smoothly morph between two frames:

generate-veo "Morph sketch into photorealistic drawing." --image ./sketch.png --last-frame ./final.png

Reference Image Styling

Style transfer using reference aesthetic:

generate-veo "A cyberpunk street scene." --ref-images ./blade_runner_ref.jpg -m fast
